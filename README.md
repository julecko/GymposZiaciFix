# Gympos ziaci Fix

A Chrome extension that fixes `gympos.sk/ziaci`. Features a toggle to enable/disable the fix.

## Installation

### From Releases
The easiest way to install the extension is by downloading the `Extension.zip` file from the [Releases](https://github.com/yourusername/GymposZiaciExtension/releases) section of this repository.

#### On Desktop (Google Chrome)
1. **Download the Zip File**:
   - Go to the [Releases](https://github.com/yourusername/GymposZiaciExtension/releases) page.
   - Download the latest `Extension.zip` file.
2. **Unzip the File**:
   - Extract `Extension.zip` to a folder on your computer (e.g., `GymposZiaciExtension`).
3. **Load the Extension in Chrome**:
   - Open Chrome and go to `chrome://extensions/`.
   - Enable "Developer mode" (toggle in the top-right corner).
   - Click "Load unpacked" and select the unzipped folder (e.g., `GymposZiaciExtension`).
4. **Test the Extension**:
   - Visit a URL like `https://gympos.sk/ziaci`.
   - If enabled, the URL should be fixed.

#### On Android (Kiwi Browser)
1. **Download the Zip File**:
   - On your Android device, go to the [Releases](https://github.com/yourusername/GymposZiaciExtension/releases) page.
   - Download the latest `Extension.zip` file.
2. **Unzip the File**:
   - Use a file manager app to extract `Extension.zip` to a folder on your device (e.g., `GymposZiaciExtension`).
3. **Install Kiwi Browser**:
   - Download [Kiwi Browser](https://play.google.com/store/apps/details?id=com.kiwibrowser.browser) from the Google Play Store.
4. **Load the Extension in Kiwi Browser**:
   - Open Kiwi Browser.
   - Tap the three-dot menu in the top-right corner and select "Extensions."
   - Enable "Developer mode" (toggle in the upper-right corner).
   - Tap the "+ (from .zip/.crx/.user.js)" option and select the unzipped folder (e.g., `GymposZiaciExtension`).
5. **Test the Extension**:
   - Visit a URL like `https://gympos.sk/ziaci`.
   - If enabled, the URL should be fixed. You can manually tap the extension icon to toggle the fix.

## Notes
- The `_metadata` folder is automatically generated by Chrome when loading the extension and is ignored in this repository (see `.gitignore`).
